# T-001 主进程与 Provider 可拆改进点盘点

## 背景 / 目标

只读审计 src/main/main.js、src/main/providers/** 与相关 scripts；输出候选任务（标题/模块/写集/验收/风险/优先级）与建议并行组；不要改源码。

## 边界（明确不做）

- 不碰写集外的文件。
- 不改 `.team/` 控制面。
- 不自行扩大范围；需要新能力先向 manager 提 CR / 改任务书。

## 依赖

（无）

## 验收

docs/audit-main-2026-11-03.md 存在；至少 5 个候选任务，每个有模块/写集/验收/风险；npm test 通过。

- 命令：`npm test`
- 证据：提交号 + 命令输出 + 文件清单（`submit` 自动记录）
- 需要人工验收？在任务里写明，并 `submit --needs-human`。

## 执行步骤

1. 读 `PROTOCOL.md`、`BULLETIN.md`、本任务书、会话简报。
2. `node .team/tools/team.mjs claim T-001 --token <token>`（必须在本任务 worktree 内）。
3. 只在写集内改；小步提交（`task(T-001): ...`）。
4. `node .team/tools/team.mjs submit T-001 --token <token>`。
5. 卡住：`report T-001 --token <token> --status blocked --note "..."`，然后停。

## 回报格式

- 改了什么（文件 / 行为）：
- 证据（命令、退出码、提交号）：
- 没做完 / 风险：
- 下一步建议：
