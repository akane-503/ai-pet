数据源

每个数据源对应一个额度来源。余额类（DeepSeek / 中转站）显示金额，窗口类（Codex / GLM / Claude 订阅）显示 5 小时 / 7 天用量。所有凭据只存在本机 。

通知

通知方式

提醒内容

RSS / Atom 订阅（可选）

用来跟踪官方博客/更新日志，例如 OpenAI、Anthropic、DeepSeek 的新闻页 RSS。网络不通的源会被静默跳过。

外观

气泡边框、文字和菜单跟随角色立绘配色。

台词生成（DeepSeek API）

定期让 DeepSeek 按每个角色的名梗写新台词（GPT 看额度、Claude 骂 A 社、鲸鱼娘吃白饭……），和内置台词一起随机出现。API Key 留空时用「数据源」里 DeepSeek 的 key。

角色立绘

鲸鱼娘保留原版；其他角色参考原娘化形象统一为大头半身画风。可为每个角色指定本机自定义图片（PNG 透明底最佳）。

活跃检测

“自动”角色模式下，桌宠根据各 agent 最近的会话写入时间判断你正在用谁：Codex（~/.codex/sessions）、Claude Code（.claude/projects，支持 WSL 路径）、Gemini CLI、Qwen Code。Codex 若被路由到 DeepSeek / GLM，会算作对应角色。


  

  

    
打开工具

    
双击角色、右键菜单「打开 …」或快捷面板「打开工具」时，按当前角色启动对应的 agent。桌面应用已经开着就只置前不重复开；CLI 每次开一个新终端窗口；网页用默认浏览器打开。留空使用内置默认值。

操作

      
    
        
  • 左键点角色：弹气泡并刷新；点气泡：切换内容；右键气泡：关闭
    • 
        
  • 拖拽：移动，松手自动吸附屏幕边缘或其他窗口；贴左边时镜像翻转
    • 
        
  • 右键角色 / 托盘图标：菜单；双击角色：打开对应工具；F12：开发者工具
    • 
        
  • 悬停角色右上角 ⋯ 打开快捷面板
