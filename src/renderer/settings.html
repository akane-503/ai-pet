扩展工具接入

添加新工具的识别规则、会话目录或模型状态文件。现有配置始终优先，重新检测不会替你改动它们。

自定义 Agent

按进程名或窗口标题认出工具，桌宠就切过去；没有自己的立绘时借用一个内置角色。填了「会话目录」还会像内置工具一样参与活跃检测（按目录最近写入判断你正在用谁）。额度在「数据源」里加一个，对应角色选它。启动路径不用填，会从运行中的进程、安装记录、快捷方式和各盘目录里自动找 exe，找不到才开网页。

接手与转接

保存后更新桌宠的转接入口。关闭时仍可查看额度、角色和工具配置。

接手技能

把 handoff / takeover 两个技能装进本机 AI 工具的 skills 目录（例如 ~/.claude/skills）。只写这两个文件夹，不动其他技能；装完再装新工具，回来补一次即可，不用重装桌宠。

正在读取本机工具…

直接转接传递本地会话引用，目标 AI 只读取指定会话的尾部，再核对项目现场。读取器不调用模型，也不上传会话。

接手来源校验

尚未校验。这里只显示会话信息，不展示聊天正文。

转接前检查

有会话读取能力的工具可作为直接转接来源。目标工具还需支持本机工具操作；网页入口需要你自行粘贴指令。源会话定位有歧义时，在桌宠的来源会话菜单中明确选择。

账号与额度

每个数据源对应一个额度来源。余额类（DeepSeek / 中转站）显示金额，窗口类（Codex / GLM / Claude 订阅 / Gemini CLI）显示窗口用量。Gemini CLI 会自动读 ~/.gemini：有中转站地址就按中转站计费显示，没地址就按官方登录查配额。所有凭据只存在本机 。

更新消息来源

启用后每 10 分钟检查 Codex、Claude Code、Gemini CLI 正式发布，以及 OpenAI 的 Tibo（@thsottiaux）。Tibo 使用第三方 X 转录，按内容分诊（加量/送额度、预告重置、故障、模型），转推与无关内容不推送；额度类提醒附上你自己账号的当前状态作对照，附原帖链接。预告不代表账号额度已重置。首次只记基线，不刷历史消息。桌宠退出时不会检查。

尚未检查

自定义 RSS / Atom（需勾选 RSS 资讯）

外观

气泡边框、文字和菜单跟随角色立绘配色。

台词生成（DeepSeek API）

定期让 DeepSeek 按每个角色的名梗写新台词（GPT 看额度、Claude 骂 A 社、鲸鱼娘吃白饭……），和内置台词一起随机出现。API Key 留空时用「数据源」里 DeepSeek 的 key。

角色立绘

鲸鱼娘保留原版；其他角色参考原娘化形象统一为大头半身画风。可为每个角色指定本机自定义图片（PNG 透明底最佳）。

检测规则

优先识别前台工具，再参考近期会话写入。默认位置按当前用户环境解析；仅需调整装在其他位置的工具。留空恢复自动探测。


  

  

    
启动覆盖

    

    
双击角色、右键菜单「打开 …」或快捷面板「打开工具」时，按当前角色启动对应的 agent。桌面应用已经开着就只置前不重复开；CLI 每次开一个新终端窗口；网页用默认浏览器打开。留空使用内置默认值；找不到或装了新工具就点「帮我找」重扫一次本机，填路径时方式会按内容自动判断。

操作

      
    
        
  • 左键点角色：弹气泡并刷新；点气泡：切换内容；右键气泡：关闭
    • 
        
  • 拖拽：移动，松手自动吸附屏幕边缘或其他窗口；贴左边时镜像翻转
    • 
        
  • 右键角色 / 托盘图标：菜单；双击角色：打开对应工具；F12：开发者工具
    • 
        
  • 悬停角色右上角 ⋯ 打开快捷面板
