name: handoff
description: 把当前任务写成交接文件，交给另一个 AI 继续（额度将尽、换工具、换会话时用）。用户说"交接""handoff""换个 AI 继续"时触发。
---

把当前对话写成交接文件，让一个零上下文的新 AI 只读它和代码就能接着干。

- 写到项目根目录的 `HANDOFF.md`；已存在就先读，保留其中的用户原话和已知坑后覆盖更新。
- 写清：目标与验收标准、用户原话（需求/约束/纠正逐字引用）、关键决策与否决的方案、当前状态（逐条标 [已验证]/[未验证]/[推测]）、已知问题（报错原文）、下一步（精确到文件/命令）。
- 进度以 `git rev-parse HEAD`、`git status --short` 和文件为准，不凭记忆。
- 规格、计划、issue、commit、diff 等已有材料只给路径或链接，不重复内容。
- 列出下一个 AI 应调用的技能。
- 去掉 API Key、密码、个人信息等敏感内容。
- 用户带了参数时，把它当作下一轮的重点来写。
- 写完把文件的 Windows 绝对路径追加一行到 `C:\Users\<用户>\.handoff\latest.txt`（WSL 下为 `/mnt/c/Users/<用户>/.handoff/latest.txt`，用 `wslpath -w` 转换；目录不存在就新建）。AI 桌宠靠这一行找到交接。
- 最后回复文件路径。
